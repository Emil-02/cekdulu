# Security Policy

## Melaporkan masalah keamanan

Jika Anda menemukan celah keamanan, laporkan secara private ke maintainer yang berwenang dan jangan membagikan detail eksploitasi di forum publik.

## Prinsip keamanan proyek

- Data sensitif seperti nomor HP dan rekening disimpan dalam bentuk hash HMAC.
- Domain dan APK hanya diproses untuk deteksi, bukan untuk eksekusi.
- Semua output disusun untuk meminimalkan false accusation.

## Tindakan respons

- Prioritaskan perbaikan sesuai tingkat ancaman.
- Jika diperlukan, lakukan pembatasan akses ke server produksi dan data moderasi.
