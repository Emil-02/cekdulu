# Kontribusi

Terima kasih mau membantu pengembangan CekDulu.

## Alur kerja

1. Fork repo ini dan buat cabang baru.
2. Jalankan `go test ./...` sebelum mengirim perubahan.
3. Pastikan perubahan tetap fokus pada keamanan, deteksi, dan manfaat pengguna.
4. Hindari menambahkan data pribadi atau informasi sensitif yang tidak perlu.

## Pedoman

- Prioritaskan explainability: alasan deteksi harus mudah dipahami manusia.
- Jaga kebersihan data sensitif: nomor HP dan rekening tidak boleh disimpan dalam bentuk plain text.
- Jangan menebar klaim yang tidak diverifikasi.
- Uji perubahan dengan unit test atau contoh kasus nyata.
